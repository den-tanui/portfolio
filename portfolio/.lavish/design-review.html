Tokyo Night Terminal Design System

A focused, high-productivity terminal aesthetic built on Tokyo Night colors, JetBrains Mono typography, and a flat-glass approach to depth. The UI stays out of the user's way — color only denotes syntax, state, or hierarchy.

KEY DECISIONS
check_circle Flat-Glass Depth

No box-shadows. Depth via semi-transparent overlays (85% opacity) + backdrop blur (10-15px). Tonal separation via 1px borders in lighter shade of background.

check_circle Sharp Corners (0px)

Every button, container, input, and tooltip has 0px border-radius. Reinforces the grid-based terminal environment.

check_circle Neovim Statusline Footer

Bottom-anchored bars follow Neovim pattern: colored "MODE" block, breadcrumbs, UTF-8 indicator, cursor position. Mimics tmux status bar.

check_circle Tmux-Style Tabs

Top nav tabs: active = Primary Blue bg with Navy text, inactive = background with thin separator. Numbered labels (0:HOME, 1:PROJECTS, etc.) for keyboard navigation.

CURRENT STATE

Fresh Next.js 16.2.10 project with Tailwind v4. The skeleton/ directory contains 8 standalone HTML pages with the Tokyo Night terminal design system. These are static prototypes — not yet integrated into the Next.js App Router. The current app/ directory has the default boilerplate (layout.tsx, page.tsx, globals.css).
