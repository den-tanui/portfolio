01. Introduction

A collection of highly optimized, interactive fuzzy finder scripts designed to supercharge your terminal workflow. These scripts leverage fzf to bridge the gap between static CLI tools and interactive power-user interfaces. Built for speed, extensibility, and pure keyboard-driven efficiency.

02. Key Features

  • ✔Git Integration: Interactive branch switching, commit browsing, and stash management.
  • ✔Process Kill: Fuzzy search and terminate processes with preview windows showing resource usage.
  • ✔Docker Explorer: Manage containers and images with live log streaming in the preview pane.
  • ✔File Navigation: Lightning fast cd and file opening using ripgrep and bat for previews.

03. Installation

bash 
# Clone the repository
git clone https://github.com/tokyo-night/fzf-scripts.git

# Move into the directory
cd fzf-scripts

# Run the install script
./install.sh

04. Usage

Most scripts are aliased for quick access. Use the fz prefix to see all available commands.

fish 
fzg   # Interactive Git branch checkout
fzk   # Interactive Process Kill
fzd   # Interactive Docker Manager
fzf-p # Search files with syntax-highlighted preview
