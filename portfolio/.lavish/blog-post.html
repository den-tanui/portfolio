mastering-fzf.md

by Alex "The Architect" Rivera

Published: October 24, 2023

#RUST #CLI-TOOLS #PRODUCTIVITY

In the modern developer ecosystem, efficiency isn't just a luxury—it's a requirement. If you aren't using a fuzzy finder, you're leaving minutes of your life on the table every single day. fzf is a general-purpose command-line fuzzy finder that changed how I interact with my system.

The Philosophy of Speed

Most tools require you to know exactly where you are going. fzf allows you to know only roughly where you are going. It's an interactive Unix filter for command-line that can be used with any list; files, command history, processes, hostnames, bookmarks, git commits, etc.

bash 
# Quick file search with preview using bat
export FZF_DEFAULT_OPTS='--preview "bat --style=numbers --color=always --line-range :500 {}"'

# Interactive cd into child directory
fd() {
  local dir
  dir=$(find ${1:-.} -path '*/.*' -prune \
                  -o -type d -print 2> /dev/null | fzf +m) &&
  cd "$dir"
}

The real power comes when you integrate fzf into your own custom scripts. Since it follows the Unix philosophy of doing one thing well—filtering text—it can be piped into almost anything.

Extending with Rust

If you're building CLI tools in Rust, integrating fuzzy finding capabilities is easier than you think. You can spawn fzf as a child process and pipe your data through its STDIN.

rust 
use std::process::{Command, Stdio};
use std::io::Write;

fn main() {
    // Data to be filtered
    let input = "rust\npython\ngo\njavascript";

    let mut child = Command::new("fzf")
        .stdin(Stdio::piped())
        .stdout(Stdio::piped())
        .spawn()
        .expect("Failed to spawn fzf");

    let mut stdin = child.stdin.take().unwrap();
    stdin.write_all(input.as_bytes()).unwrap();
}

Mastering these workflows creates a "flow state" environment where the friction between thought and execution disappears. The terminal isn't just a place to run commands; it becomes an extension of your intent.
