## Overview

A modular dotfiles framework that installs and configures development environments from a single YAML manifest.

## Features

- **Modular**: Each tool has its own config file under `modules/`
- **Secret management**: Encrypted secrets via `age` + `sops`
- **Bootstrap**: One-command setup on any new machine
- **Multi-OS**: Linux and macOS support

## Bootstrap

```bash
curl -fsSL https://dotfiles.example.com/bootstrap | bash
```

This installs Homebrew (or pacman), stows configs, and runs post-install hooks.
